# Java OOP Projects

My hands-on journey learning object-oriented programming in Java, starting with classes and objects and progressing through the four OOP pillars.

Each project focuses on a specific concept and includes source code, a brief project README, and detailed learning notes.

## Learning Roadmap

| Project | Concepts | Status |
|---|---|---|
| [OOP Basics — Student Profile](01-oop-basics-student-profile/) | Classes, objects, fields, references, instance methods, constructors, and `this` | Code completed |
| [Encapsulation — Bank Account](02-encapsulation-bank-account/) | Private fields, controlled access, and validation | Code Completed |
| Inheritance — Employee Details | Parent and child classes, `extends`, and `super` | Planned |
| Polymorphism — Shape Calculator | Method overriding and parent-type references | Planned |
| Abstraction — Notification System | Interfaces and different implementations | Planned |

## Repository Structure

Each completed project contains:

- `README.md` — project summary, concepts covered, and running instructions.
- `NOTES.md` — detailed concept explanations and examples.
- `src/` — Java source files.

## Learning Approach

Understand the concept, implement a small example, test its behaviour, and document what I learned.

These are focused learning projects. Collections, databases, and frameworks are outside this repository's current scope.
